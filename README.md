# CoDuck · كابتن بطة — التحديثات

هنا بتتنشر نسخ CoDuck الجديدة. البرنامج بيدوّر هنا لوحده مرة كل يوم.

كل نسخة فيها ملف APK واحد، ونص النسخة لازم يكون فيه السطور دي:

```
code: 101
sha256: <بصمة الملف>
required: false
```

- `code` رقم النسخة (versionCode)، ولازم يكون أكبر من النسخة اللي عند الناس.
- `sha256` البرنامج بيتأكد منها قبل ما يثبّت.
- `required: true` معناها إن التحديث لازم ومفيش «بعدين».

البرنامج كمان بيتأكد إن الملف متوقّع بنفس مفتاح CoDuck، فمحدش يقدر يحط نسخة غريبة.
